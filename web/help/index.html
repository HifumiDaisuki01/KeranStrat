训练操作需要对应模式的白名单权限，三套权限独立。KS、KSV、KSD 共用服务器，同一时间只能运行一种；进入训练、切图和退出可能影响全服。查看帮助无需权限。

快速上手

示例名称可自行替换。每次发出录制指令后，等倒计时结束再行动；完成动作后发送 stop。

KS

KS · 录一套战术

  1. 进入训练，选择 T 或 CT，等出生。

    !ks practice

  2. 按 B 买好装备，站到起点，新建战术。

    !ks new 我的战术

  3. 倒计时结束后行动，完成后停止。

    !ks record 1
!ks stop

  4. 换编号继续录；保存后即可回放。

    !ks save
!ks play
KSV

KSV · 双方 BOT 对打

  1. 进入训练，选择 T，创建场景。

    !ksv practice
!ksv new 双方演练

  2. 买好装备并设置 T 起点，录制 T1。

    !ksv anchor t
!ksv record t 1
!ksv stop

  3. 切到 CT，买好装备，录制 CT1。

    !ksv anchor ct
!ksv record ct 1
!ksv stop

  4. 保存并模拟；其他真人先转观察者。

    !ksv mode hybrid
!ksv save
!ksv play
KSD

KSD · 真人守点

  1. 先有一套已保存的 T 方 KS 战术；进入训练并选择 CT。

    !ksd practice

  2. 加载进攻战术，买好装备并走到防守点。

    !ksd load B区进攻
!ksd position

  3. 朋友进 CT 后各自加入并保存位置。

    !ksd join
!ksd position

  4. 房主确认队伍就绪后开始。

    !ksd team
!ksd start
结束本次训练：KS 用 !ks exit，KSV 用 !ksv exit，KSD 房主用 !ksd exit，恢复 Dust2 死斗。stop 只停止当前操作，不退出训练。

指令大全

<参数> 必填，[参数] 可选，t|ct 表示二选一，不要输入尖括号或竖线。1000 毫秒 = 1 秒。队员编号为 1–5（受服务器配置上限约束），可以只录 1、3、5。

!ks save
!ks save

常见问题

我想用 AWP 加双闪录制，怎么配装？

进入训练并出生后按 B 购买。KS 也可用 !ks kit awp。录制保留当时已有的武器与投掷物；不用担心回到起点时被强制改成 AK。KSV、KSD 直接按 B 配装；KSD 买好后保存 position，改装后重新 start。

为什么打开 X 光还是看不到？

仅 KS、KSV 回放中，对应模式已授权的观察者才能看到。先切到观察者，再 !ks load 名称 → !ks xray on → !ks play。KSV 操作者 play 后自动转观察者。观察者没有存活角色，不能录制；回到对应 T/CT 后再录制。KSD 不支持 X 光。

AI 交接与 offset 有什么区别？

offset 是角色晚多久开始；handoff 是开始后多久从录制转 AI。例如 offset 1500、handoff 3000 表示统一起点后 1.5 秒开始，该角色播放 3 秒后交接。交接不能超过轨迹长度，不确定就用 auto。普通 KS 不支持交接；KSV 必须使用 hybrid。

为什么提示模式占用或不能编辑？

先停止正在运行的录制或回放。KSV 由当前操作者使用 !ksv exit 释放；KSD 房主可用 !ksd close 解散会话并保留训练环境。KSD 普通成员只能管理自己的加入、退出和位置。

KSD 队友死了会立刻复活吗？

不会。本轮死亡后等待，其他队友继续防守。下一轮由防守回合管理器统一复活和恢复各自位置装备；普通训练的自动复活不适用于 KSD。

保存的战术是我独享的吗？

KS 按地图共享战术库，有权限的玩家可轮流 load 同一套战术编辑。新建时同地图名称不能重复。KSV 使用独立共享场景库和会话操作权，与 KS 文件不互通。KSD 只读引用 KS 的 T 方战术，防守位置按成员独立保存。

为什么不能加载，或者提示没有权限？

三种模式白名单独立，请联系管理员核对。战术按地图存放，先确认当前地图；游戏更新导致录制版本或 Tick 不兼容时，需重新录制。用对应模式的 status 查看具体错误。

需要暂停：!ks stop / !ksv stop / !ksd stop。需要退出：使用当前模式的 exit。
